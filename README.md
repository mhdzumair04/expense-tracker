
# My Expense Tracker

A simple expense tracker built using HTML, CSS, and JavaScript.

## Features

- Add expenses with a name, amount, category, and date
- View the total amount spent
- Count the number of expenses
- Filter expenses by category
- Delete expenses
- Save expenses using browser local storage
- Responsive layout for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

## Project Structure

expense-tracker/
- index.html
- style.css
- script.js
- README.md

## Note

Expenses are stored in the current browser. They are not
synchronized between devices or browsers.
